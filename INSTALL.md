# Installing Focus Guard from the APK

No computer needed. Takes about three minutes.

Focus Guard leaves YouTube Shorts and the Instagram Reels tab as soon as they open. It does not change those apps, has no internet access, and reads only view ids, never on-screen text.

## 1. Get the file onto the phone

Receive `focus-guard-<version>.apk` over WhatsApp or Telegram (sent as a document) or from Google Drive. Gmail blocks `.apk` attachments.

## 2. Install it

1. Tap the file.
2. Android asks whether the app you opened it from may install apps. Allow it.
3. If Play Protect or the phone's own scanner warns about an unknown app, choose to install anyway.

If the install fails with "App not installed", an older copy signed with a different key is still on the phone. Uninstall it first, including from a work profile or second space, then try again.

## 3. Finish the setup screen

Open Focus Guard and work down the list. Each step has a button that opens the right settings page.

1. **Accessibility access.** Tap **Turn on**, find Focus Guard in the list, and switch it on.
   If Android shows "Restricted setting" instead: go back, tap **Allow restricted**, open the ⋮ menu, choose **Allow restricted settings**, then tap **Turn on** again.
2. **No battery limits.** Tap **Allow**.
3. **Autostart** (Xiaomi / POCO only). Tap **Open** and switch Autostart on for Focus Guard.
4. **Battery saver** (Xiaomi / POCO only). Tap **Open** and choose **No restrictions**.

Without steps 3 and 4, Xiaomi and POCO phones stop the blocker after a while.

## 4. Check that it works

Open YouTube and go to Shorts. You should be sent straight back.

## Good to know

- The blocked screen can flash for a moment before you are sent back.
- The Shorts shelf on the YouTube home feed counts as Shorts.
- The switches at the bottom of the Focus Guard screen turn individual rules off.
- A YouTube or Instagram update can break a rule until Focus Guard is updated.
- To remove it, uninstall Focus Guard like any other app.
